Questions

Frequently asked

Is Queramusic really free?
Yes. The core player is completely free to download and use, with no advertisements, no feature paywalls and no subscription. Optional premium support is available if you want to contribute to development.
Does it collect any personal data?
No. Queramusic contains no telemetry, no analytics SDKs and no advertising identifiers. There are no accounts and no sign-in. The application does not need an internet connection to function — your library is scanned and indexed entirely on your machine.
Which audio formats are supported?
FLAC, ALAC, WAV, AIFF, APE, MP3, AAC, OGG, Opus and WMA are supported out of the box, with resolutions up to 384 kHz / 32-bit in lossless bit-perfect mode.
Will it work on my computer?
Queramusic runs on Windows 10 (64-bit) and Windows 11. A separate 32-bit legacy build is available for older hardware — look for it in the download window.
How do updates work?
If you install through the Microsoft Store, updates are delivered automatically. If you use the standalone installer, simply download the latest build and install it over your existing version — your settings and library index are preserved.
